In this, I made 2 simple C programs to help me learn about C!

## Calculator
This is a calculator that allows you to type two numbets in and the operation with some fun ascii art! It supports multiple operator aliases (e.g. -, m, s for subtraction) and makes sure you dont divide numbers by 0!

## Word counter
It reads the total number of lines and words in a `repeated.txt` using fgets and tracks the previoud character to track when a word ends and the new one starts.
